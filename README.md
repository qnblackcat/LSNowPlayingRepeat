# LSNowPlayingRepeat

<img width="1097" height="504" alt="image" src="https://github.com/user-attachments/assets/8c2b32ad-e223-496d-98aa-0af3c1a6e45b" />

- A Repeat button for the Lock Screen and Control Center Now Playing controls. Tap to cycle Off → All → One.

| iOS | Replaces | Long-press |
|---|---|---|
| 17.1+ | Favorite (⭐) | Toggle Favorite |
| 16.x– 17.0.x | Audio output button | Open the output picker |

- Works with Apple Music, YouTube Music and Spotify. Other apps, the Dynamic Island and StandBy are left as is.

- **Requires** iOS 16.0+ and later. Tested on 16.3.1 and 17.1.1.
